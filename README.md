# Author Prediction Chatbot

A machine learning project that predicts the likely author of a text passage based on writing style.

## Model

The final model uses character-level 3-grams and 5-grams with TF-IDF and Logistic Regression.

## Performance

- Accuracy: 98.05%
- Precision: 98.08%
- Recall: 98.05%
- F1-score: 98.05%

## Dataset

Standardized Project Gutenberg Corpus (SPGC).
